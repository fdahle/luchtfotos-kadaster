Luchtfoto's Kadaster

Historical Kadaster aerial photographs, georeferenced through IIIF and published as Allmaps Georeference Annotations, with Resource Control Points tying the photographs together. Each link opens in the Allmaps Viewer.

Test set: positions are fitted to the current PDOK orthophoto, working backwards through time, at about 1.5–2.5 m RMSE per photo. That is agreement with modern imagery, not surveyed ground control. See the repository for the file layout and method.
